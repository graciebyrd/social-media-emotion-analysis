# Social Media Usage and Emotional Well-Being Analysis

## Project Overview

This project investigates relationships between social media usage patterns and reported emotional well-being using Python, exploratory data analysis, and statistical testing.

The analysis examines how engagement frequency, preferred social media platform, daily usage time, and age relate to users' reported dominant emotions.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook

## Research Questions

- Is greater social media engagement associated with negative emotions?
- Does the distribution of dominant emotions differ across social media platforms?
- Is daily usage time associated with reported emotions?
- How does age vary across emotional categories?

## Methodology

The project includes data validation, cleaning, descriptive statistics, exploratory visualizations, and a chi-square test of independence.

Visualizations include boxplots, stacked bar charts, and comparisons of average age across emotional categories.

## Key Findings

- Higher social media engagement was not consistently associated with more negative emotions in the exploratory comparisons.
- The chi-square test indicated a statistically significant association between primary social media platform and reported dominant emotion.
- The analysis explored differences in daily usage time and age across emotional categories.

These findings describe associations within the dataset and do not establish that social media usage causes particular emotional outcomes.

## Dataset

*Social Media Usage and Emotional Well-Being* by Emirhan Bulut (2024), available through Kaggle.
